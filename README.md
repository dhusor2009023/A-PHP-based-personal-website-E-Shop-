# 🐦 Online Bird Shop Management System

## 📌 Project Overview

This project is a web-based Bird Shop Management System developed using PHP and MySQL/Oracle.
It allows admin users to manage bird products, categories, customers, and orders through a dashboard.

## 🎯 Features

* Admin dashboard for full control
* Add, edit, delete bird products
* Product category management
* Customer management
* Order management system
* Image upload for products

## 🛠️ Technologies Used

* PHP (Backend)
* HTML, CSS, JavaScript (Frontend)
* MySQL / Oracle Database
* Apache Server (XAMPP)

## 📂 Project Structure

* `admin_area/` → Admin panel
* `includes/` → Database & core functions
* `css/` → Styling
* `js/` → Scripts
* `images/` → Product images

## ▶️ How to Run

1. Install XAMPP / Apache
2. Move project folder to `htdocs`
3. Start Apache & MySQL
4. Import database file 
5. Open browser:
http://localhost/online%20pet%20shop/
http://localhost/phpmyadmin/
http://localhost/online%20pet%20shop/admin_area/insert_product.php
http://localhost/online%20pet%20shop/admin_area/index.php?view_payments


## 🔐 Security Considerations

* Database credentials are not removed
* Input validation required for production use
* No authentication hardening (can be improved)
